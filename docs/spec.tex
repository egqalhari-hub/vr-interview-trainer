\textbf{Overview.} A WebXR/three.js r160 single-page app (ES modules + import map, vendored \texttt{three}, \emph{no build step}) simulating a strict Korean job interview on Meta Quest~2 (\texttt{immersive-vr}, \texttt{local-floor}, own ``VR \emph{ipjang}'' button; Meta Quest Browser) and on desktop Chrome (mouse-drag look). One E2E workflow: dressing room (hair / outfit / industry) $\rightarrow$ greeting bow $\rightarrow$ 3 fixed questions (\emph{jagisogae} self-introduction, \emph{jiwondonggi} motivation, \emph{jangdanjeom} strengths/weaknesses), each with exactly 1 adaptive follow-up, voice answers via push-to-talk $\rightarrow$ weighted report board (content / attitude-gaze / attire, S/A/B/C grade). Mock mode (default, zero network) $\leftrightarrow$ live mode (OpenAI key in \texttt{localStorage}); \emph{any} API error falls back to mock for that call only, so a demo can never hard-fail.

\textbf{Data flow.}
{\footnotesize
\begin{enumerate}\setlength{\itemsep}{0pt}
  \item DRESS: panel clicks set hair (black/brown/blond/blue), outfit (suit/casual/training), industry (corp/startup/public); avatar at mirror updates.
  \item Confirm $\to$ attire scored (rubric in mock; gpt-4o vision on avatar screenshot in live).
  \item INTERVIEW greeting: interviewer speaks (TTS + jaw bob, subtitles in \texttt{\#sub}); system waits for bow (pitch $\le -35^\circ$).
  \item Q1--Q3 asked in order; user holds push-to-talk and answers by voice.
  \item Live: MediaRecorder $\to$ whisper-1 (ko) $\to$ transcript; mock: next canned transcript.
  \item Each answer $\to$ gpt-4o-mini evaluation JSON (score + feedback) and one adaptive follow-up; mock: canned score + canned follow-up.
  \item Every frame, telemetry reads camera/HMD pose $\to$ eyePct / fidget / bows $\to$ live HUD.
  \item REPORT: content = mean of 6 scores; board shows content / body / attire, weighted total, S/A/B/C grade, feedback.
\end{enumerate}}
\vspace{-4pt}

\textbf{Key formulas.} Attire: base 70, outfit suit $+20$/casual $+5$/training $-15$, hair black $+10$/brown $+5$/blond $-5$/blue $-15$; startup halves negative adjustments; public sector extra $-5$ for blond/blue hair; clamp $[0,100]$. Verified: suit/black/corp $=100$, casual/brown/startup $=80$, training/blue/corp $=40$. \;
\texttt{bodyScore} $=\mathrm{clamp}(\texttt{eyePct}\cdot100-\texttt{fidget}\cdot40+\min(\texttt{bows},2)\cdot5,\,0,\,100)$. \;
\texttt{content} $=$ mean of 6 answer scores (mock: $[82,85,74,78,81,80]\to80$). \;
\texttt{total} $=0.5\,\texttt{content}+0.3\,\texttt{body}+0.2\,\texttt{attire}$; grade S $\ge90$, A $\ge80$, B $\ge70$, else C.

\textbf{Status.} Developed and verified on the macOS desktop simulator (headless boot smoke check + full mock E2E run). Quest~2 WebXR deployment path implemented; \emph{on-device test pending} (no hardware access in stage 1). Stage 2: Unity port, on-device verification, hand tracking, real lip-sync, multi-interviewer panel, backend proxy for API keys.
